# DSA & SQL Problem Solving

This repository contains my solutions to **Data Structures and Algorithms (DSA)** and **SQL** problems from LeetCode in Python and SQL.

The goal of this repo is to build strong problem-solving skills by implementing optimal solutions, along with dry runs, time complexity, and space complexity analysis for every problem.
